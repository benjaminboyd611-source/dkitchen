# 🏛️ Дума на цифровой кухне

Это программа для сбора свежих законопроектов из Госдумы (СОЗД) и генерации удобного HTML-файла с подсказками для ИИ-ботов (Алиса, ChatGPT и т.д.).

## 🚀 Как пользоваться на Windows (Без установки Python)

Каждый раз, когда код в этом репозитории обновляется, GitHub автоматически собирает готовый `.exe` файл для Windows.

**Шаг 1. Скачайте готовую программу**
1. Откройте вкладку **Actions** вверху.
2. Нажмите на последний успешный запуск **Build Windows EXE**.
3. В самом низу страницы скачайте архив **DumaKitchen-Windows-Ready**.
4. Распакуйте его в любую папку.

**Шаг 2. Запустите**
1. Дважды кликните на `DumaKitchen.exe`.
2. Дождитесь окончания парсинга. Окно само не закроется, пока вы не нажмете Enter.
3. Рядом появится файл `index.html`. Откройте его в любом браузере!

## 📱 Telegram-бот (Опционально)
Если вы хотите, чтобы программа после завершения отправляла 5 главных законопроектов вам в Телеграм:

1. Переименуйте файл `.env.example` в `.env`.
2. Откройте его в Блокноте и впишите туда ваши данные:
   ```text
   TELEGRAM_BOT_TOKEN=123456789:ABCDefgh...
   TELEGRAM_CHAT_ID=-100123456...
   ```
3. Запустите `DumaKitchen.exe` снова. Программа сама подхватит настройки и пришлет сообщение.
