# 🏛️ Дума на цифровой кухне

Парсер свежих законопроектов из базы Госдумы (СОЗД), который помогает переводить сухой чиновничий и юридический язык на понятный человеческий с помощью ИИ. 

Программа собирает последние инициативы и генерирует удобный HTML-файл. Под каждым законом есть кнопка **«Assist Mode»**, которая выдает готовый промпт для Алисы, GigaChat или ChatGPT. Промпт заставляет нейросеть искать **pro и contra (плюсы и минусы)**, выгодоприобретателей и оценивать **применимость закона в реальном мире**.

---

## 👩‍🍳 Для обычных пользователей (Без установки Python)

Вам не нужно ничего программировать или устанавливать. GitHub сам собирает готовую программу.

**Шаг 1. Скачайте готовую программу**
1. Перейдите во вкладку [**Actions**](https://github.com/benjaminboyd611-source/dkitchen/actions).
2. Нажмите на самую верхнюю сборку с зеленой галочкой ✅ (называется *Build Apps (Win & Mac)*).
3. Прокрутите страницу в самый низ до раздела **Artifacts**.
4. Скачайте нужную версию:
   - **`DumaKitchen-Windows`** (для ПК на Windows)
   - **`DumaKitchen-Mac`** (для Apple MacBook)
5. Распакуйте скачанный архив в любую удобную папку.

**Шаг 2. Запустите**
- **На Windows:** Дважды кликните на `DumaKitchen.exe`. 
- **На Mac:** Кликните по файлу `DumaKitchen-Mac` *правой кнопкой мыши* (или двумя пальцами) -> выберите **«Открыть»**.
- Дождитесь окончания загрузки законов. Окно программы скажет вам, когда всё будет готово.
- В этой же папке появится файл `index.html`. Просто откройте его в любом браузере!

## 👨‍💻 Для хакеров и разработчиков

Если вы хотите запускать скрипт из исходников или доработать его:

```bash
# 1. Клонируем репозиторий
git clone https://github.com/benjaminboyd611-source/dkitchen.git
cd dkitchen

# 2. Устанавливаем зависимости
pip install -r requirements.txt

# 3. Запускаем парсер
python main.py
```
После запуска в корне появится актуальный `index.html`.

## 📱 Telegram-бот (Опционально)

Программа может не только делать HTML-файл, но и присылать 5 самых свежих законопроектов вам в Telegram.

1. Найдите в скачанной папке файл `.env.example`.
2. Переименуйте его в `.env`.
3. Откройте в Блокноте/TextEdit и впишите свои данные (без пробелов после `=`):
   ```text
   TELEGRAM_BOT_TOKEN=123456789:ABCDefgh...
   TELEGRAM_CHAT_ID=-100123456...
   ```
4. Запустите программу снова. Она сама подхватит настройки и отправит дайджест в чат!
