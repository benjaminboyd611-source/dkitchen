# 🏛️ Дума на цифровой кухне

Парсер свежих законопроектов из базы Госдумы (СОЗД), который помогает переводить сухой чиновничий и юридический язык на понятный человеческий с помощью ИИ. 

Программа работает локально на вашем компьютере. Это позволяет обходить государственные блокировки (Qrator/Kaspersky), так как запросы идут с вашего домашнего IP-адреса. Программа скачивает последние инициативы и генерирует удобный HTML-файл. 

Под каждым законом есть кнопка **«Assist Mode»**, которая выдает готовый промпт для Алисы, GigaChat или ChatGPT. Промпт заставляет нейросеть искать **pro и contra (плюсы и минусы)**, скрытых выгодоприобретателей и оценивать **реальную применимость закона**.

---

## 👩‍🍳 Для обычных пользователей (Без установки)

Вам не нужно ничего программировать. Скачайте программу, запустите, и она сама соберет данные и откроет браузер с законами!

**Шаг 1. Скачайте программу**
1. Перейдите во вкладку [**Actions**](https://github.com/benjaminboyd611-source/dkitchen/actions).
2. Нажмите на самую верхнюю сборку с зеленой галочкой ✅ (*Build Apps*).
3. Прокрутите страницу в самый низ до раздела **Artifacts**.
4. Скачайте нужную версию: **`DumaKitchen-Windows`** (для ПК) или **`DumaKitchen-Mac`** (для Apple).
5. Распакуйте скачанный архив.

**Шаг 2. Запуск и обход защиты системы**
Программа создана энтузиастом, у нее нет корпоративного сертификата. Ваш компьютер попытается вас защитить — это нормально для новых файлов.
- 🪟 **На Windows:** При запуске появится синее окно "Система Windows защитила ваш ПК". Нажмите мелкую надпись **«Подробнее»**, а затем кнопку **«Выполнить в любом случае»**.
- 🍏 **На Mac:** Кликните по файлу `DumaKitchen-Mac` *правой кнопкой мыши* (или двумя пальцами) и выберите **«Открыть»**. Подтвердите запуск в окне.

Дождитесь закрытия черного окна (обычно 10-20 секунд). Программа **сама откроет** страницу с законами в вашем браузере!

## 👨‍💻 Для хакеров и разработчиков

Если вы хотите запускать скрипт из исходников или доработать его:

```bash
git clone https://github.com/benjaminboyd611-source/dkitchen.git
cd dkitchen
pip install -r requirements.txt
python main.py
```

**Telegram-бот (Опционально):**
В базовой сборке отправка в Telegram отключена для надежности компиляции. Чтобы бот заработал при запуске из исходников:
1. Создайте файл `.env` (см. `.env.example`) с токеном `TELEGRAM_BOT_TOKEN`.
2. Если необходимые библиотеки установлены, скрипт автоматически подхватит модуль и отправит дайджест в чат.
