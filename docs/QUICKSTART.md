# Quickstart

## Локально

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## GitHub Actions

1. Залей проект в GitHub.
2. Открой Actions.
3. Запусти workflow `Update SOZD data`.
4. Скачай artifact или открой обновлённые файлы `data/`.
