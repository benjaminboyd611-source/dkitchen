# Telegram setup

## 1. Создай бота
Открой Telegram, найди @BotFather и выполни команду `/newbot`.

## 2. Сохрани токен
BotFather пришлет токен формата:
`123456789:AA...`

## 3. Добавь бота
- в личный чат, или
- в группу, или
- в канал (если канал — добавь бота как администратора)

## 4. Узнай chat_id
Самый простой путь — написать сообщение боту или в группу, а потом использовать любой удобный способ получения `chat_id`.

## 5. Добавь secrets в GitHub
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

## 6. Запусти workflow
После запуска бот пришлет короткий дайджест по 5 свежим законопроектам.
